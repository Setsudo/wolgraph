- `CLAUDE.md` — agent conventions and commands; keep under 60 lines
- `docs/SPEC.md` — MVP scope, data model, design decisions; change only with owner approval
- `docs/PLAN.md` — task list and status; tick tasks as they are accepted
- `filemap.md` — this index; update when adding or moving files
- `AGENTS.md` — Next.js-managed agent notes; rewritten by `next dev`, commit as is
- `package.json`, `package-lock.json` — npm scripts and dependencies
- `next.config.ts`, `tsconfig.json`, `eslint.config.mjs`, `.prettierrc.json`, `.prettierignore` — build, types, lint, format config
- `vitest.config.mts` — unit tests (`*.test.ts`, node) and component tests (`*.test.tsx`, jsdom)
- `playwright.config.ts`, `e2e/` — Playwright e2e specs; `PLAYWRIGHT_CHROMIUM_PATH` overrides the browser binary
- `.env.example` — required env vars (Supabase URL and anon key)
- `.github/workflows/ci.yml` — CI: install, lint, typecheck, unit tests
- `app/layout.tsx`, `app/globals.css` — root layout; theme tokens (`@theme`)
- `app/page.tsx` — redirects to `/day/<today>`
- `app/(auth)/login/page.tsx` — sign-in (placeholder)
- `app/(app)/layout.tsx` — signed-in shell with main nav
- `app/(app)/day/[date]/page.tsx`, `app/(app)/trends/page.tsx`, `app/(app)/categories/page.tsx` — app screens (placeholders)
- `lib/date.ts` — local-date helpers (`todayLocal`)
- `lib/wheel/geometry.ts` — pure two-ring wheel layout, SVG paths, hit testing, fill opacity
- `supabase/migrations/` — SQL migrations (schema, RLS, seed); add new files, never edit applied ones
- `supabase/test/auth_stub.sql` — stub `auth` schema and roles so migrations run in PGlite tests
- `lib/data/types.ts` — `Database` and row types matching the migrations
- `lib/data/schema.test.ts` — schema, constraint and RLS tests (PGlite)
- `lib/data/period.ts` — week/month period math on YYYY-MM-DD strings (UTC-safe)
- `lib/data/aggregates.ts` — per-period totals and per-day averages per main category
- `lib/radar/geometry.ts` — pure radar chart geometry (axes, scale, polygons, labels)
- `lib/data/trends.ts` — `getTrendData(period)`: server-side load of categories and period entries, aggregated
- `lib/trends/format.ts` — trends period labels, hour formatting, `?kind&anchor` parsing and hrefs
- `components/Radar.tsx` — pure SVG radar of average hours per day per main category
- `components/trends/` — trends screen: `TrendsView` (shared tree), `PeriodControls` (client toggle and arrows), `TrendsBody`, `TotalsTable`, `CanonicalizeTrendsUrl` (client redirect to today)
- `app/dev/trends-preview/` — dev-only trends preview with fixture data (`?kind&anchor&empty=1&few=1`); 404 in production
- `proxy.ts` — Next 16 proxy (middleware): session refresh and route protection
- `lib/supabase/` — `env.ts`, server/browser clients, `proxy.ts` session refresh
- `lib/auth/routing.ts` — pure redirect rules and `next` sanitizer
- `app/auth/callback/route.ts` — magic-link code exchange
- `app/(auth)/login/LoginForm.tsx` — client login form (states: default, sending, sent, error)
- `components/SignOutButton.tsx` — nav sign-out
- `e2e/smoke.spec.ts` — credential-free smoke tests
